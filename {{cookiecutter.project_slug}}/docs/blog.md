# 博客模块

博客模块提供可复用的 CMS 能力：管理员在后台配置分类、作者和文章，前台无需登录即可浏览。

## 安装与启用

依赖由 uv 统一管理。博客模块已随项目默认启用，首次部署执行迁移即可：

```bash
uv run python manage.py migrate
```

如需覆盖 CKEditor 5 的上传路径或工具栏，修改 `__PROJECT_PACKAGE__/settings/base.py` 中的
`CKEDITOR_5_UPLOAD_PATH` 和 `CKEDITOR_5_CONFIGS`。

## 后台配置

进入管理后台的“博客”菜单：

1. **文章分类**：维护分类名称、Slug、描述和排序。
1. **作者**：维护前台展示用的作者名称、头像、简介和邮箱；可关联到用户账号。
1. **文章标签**：维护标签名称和 Slug。
1. **文章**：创建并发布文章。

### 文章内容格式

文章支持两种内容格式，通过“内容格式”字段切换：

- **富文本**：使用 CKEditor 5 编辑器，支持图片拖拽上传，内容保存在 `content_html`。
- **Markdown**：使用普通文本框填写 Markdown 源码，前台通过 `markdown-it` 渲染。

切换格式时，必须填写对应的内容字段；另一字段可留空。

### 文章状态

- **草稿**：仅后台可见，前台无法访问。
- **已发布**：填写发布时间后前台可见；未到发布时间也不会展示。
- **已归档**：前台不可见。

文章支持置顶和排序，列表页按“置顶 → 发布时间”倒序展示。

## 前台页面

| URL | 说明 |
|-----|------|
| `/blog/` | 文章列表，支持分页 |
| `/blog/category/<slug>/` | 按分类筛选文章 |
| `/blog/category/` | 分类列表 |
| `/blog/tag/<slug>/` | 按标签筛选文章 |
| `/blog/<slug>/` | 文章详情 |

所有前台页面均无需登录。文章详情页会自动累计阅读量，详情底部展示同分类相关文章。

## 图片上传

- 文章封面、作者头像、文章附图均使用 `ImageField`。
- 上传文件会被重命名为 UUID，按日期分目录存储在 `media/blog/` 下。
- 富文本内图片通过 CKEditor 5 上传到 `media/blog/ckeditor/`。

## 数据边界

本模块提供基础的分类、标签、作者、文章和附图模型，不包含评论、点赞、订阅、SEO
元标签、定时发布任务、全文搜索和多语言。后续业务主题可按需扩展。
